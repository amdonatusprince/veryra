# Brand — Veyra

_Status: active_

Working brand for the hackathon build, taken from the locked positioning and the two UI references: a Zoon-style operator console, and a card-first membership NFT. Replace this file by running brand-design if you want a different palette.

## Voice

Calm and exact. Veyra is infrastructure, not a points campaign.

Use: programme, membership, vault, bound account, transfer, access right.
Avoid: unleash, seamless, next-gen, revolutionary, loyalty in the protocol name.

Tagline: The infrastructure for programmable ownership.
Supporting line: Build assets that own, earn, interact and evolve.

## Palette

Warm paper for the product chrome. Ink and brass for the membership card. One green action color.

| Token | Hex | Use |
|---|---|---|
| paper | `#f4f1ea` | App background |
| ink | `#1b1914` | Primary text |
| fir | `#1f4a3a` | Primary actions |
| brass | `#8d5e1a` | Tier metal, card accent |
| card | `#14120e` | Membership card surface |
| card-text | `#f6f1e7` | Text on the card |

Fir on paper and card-text on card both clear WCAG AA. Brass is for large tier labels and the card rule, not for small body text.

## Type

- Display: Newsreader
- UI: Figtree
- Numbers and account ids: the UI font with tabular figures

## Shape

Cards use a 12 px radius and a 1 px border. The membership card is the only surface that goes dark. Do not mix shadow and border on the same element.
